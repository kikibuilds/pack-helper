＋ 手动添加订单

平台拉不到、或者线下卖出的订单，可以在这里手动加。加进已有包裹的，会和那个包裹装同一个箱子、共用一张面单。

发货文件保存位置

发货文件保存在：Chrome 的「下载内容」文件夹 / 发货 / 发货_日期时间 /
这里可以改子文件夹的名字（可以多层，例如 发货/2026）。要换整个根目录（比如换到另一个磁盘），请到 Chrome 的「设置 → 下载内容 → 位置」里改 —— Chrome 只允许扩展把文件存在下载文件夹里面。
改了子文件夹不影响发邮件。

待发货列表页地址

「一键拉取订单」会依次打开这些页面。第一格填列表页地址（留空表示跳过该平台）；第二格填打开后要先点的筛选按钮上的文字，例如 Depop 的「To ship」。

订单详情链接规则

已打包记录

打包下载过的订单会被记住（45 天）。之后再拉取时，如果平台上还显示待发货，会标「之前打包过」并默认不勾选，避免重复发货。

人不在电脑旁时，用手机发一封邮件到发件邮箱（「设置 → 邮件账号」里那个 Gmail），这台电脑会自动拉取订单、打包、发邮件给下面选的收件人，再回信告诉你结果。
前提：这台电脑开着、不睡眠，Chrome 开着，三个平台在 Chrome 里保持登录。发件邮箱、密送、邮件标题和正文和「设置 → 邮件账号」共用一套。
